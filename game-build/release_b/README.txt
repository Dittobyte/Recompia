Pokopia PC @VERSION@

1. Run PokopiaLauncher.exe and pick your dump folder (base/ and updates/<version>/, each with exefs/ and romfs/). Version 2.0.1a is required.
2. Press Set up. It builds pkp.exe and the shader cache on this PC. You can pause and continue later.
3. Press Play.

Updating: extract the new release over your install. If the update changes the game code, the launcher says so: press Set up again and it rebuilds pkp.exe (about 7 minutes). Your shaders and saves are kept.

Upscaling: FSR 3 works out of the box (F1, Graphics). DLSS / DLAA need an NVIDIA RTX GPU and a file NVIDIA licenses separately: the launcher's Game files page has a button that downloads it from NVIDIA.
