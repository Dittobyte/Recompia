prompt_icons.pak: 822 RGBA 36x36 controller, touch, keyboard and mouse prompt icons (xbox/, ps/, steam/, deck/ Steam Deck, ns1/ Nintendo Switch, ns2/ Nintendo Switch 2, wiiu/, frame/ Steam Frame, index/ Valve Index, touch/, kbm/; each base icon also has a gold _pressed twin), built from the Kenney Input Prompts 1.5a pack (CC0, see LICENSE-Kenney-InputPrompts.txt).
Format: "MPIP" header, 48-byte directory entries (name, offset, size), then raw RGBA8 pixel blocks; entries sorted by name.
Rebuild: python -I scripts/build_prompt_pack.py --kenney <Kenney pack folder or zip> --out assets/prompts/prompt_icons.pak [--preview <png>]
Check: python -I scripts/build_prompt_pack.py --verify assets/prompts/prompt_icons.pak
Keys without a Kenney image (keypad digits, F13-F24, media keys, etc.) are drawn as text on the blank key cap ("keyboard" image) with DejaVu Sans.
The d-pad direction icons (<set>/dpad_up ... <set>/dpad_right) are drawn from the whole d-pad (one arm kept, the rest dimmed; Kenney's own direction art marks the arm in red); index/ and touch/ use Kenney's stick and swipe directions. --derive adds them to an older pack.
Controller sets come from the Kenney folders named in PAD_SETS (build_prompt_pack.py). Add or replace some sets in place, keeping every other entry byte for byte: python -I scripts/build_prompt_pack.py --add-sets <Kenney pack folder or zip> --sets deck,ns1 --out assets/prompts/prompt_icons.pak
steam/ is the Steam Controller (2026): Kenney's original-controller art, fitted afterwards (View and Menu from xbox/, four rear grips l4 l5 r4 r5 drawn from the original grip shape, guide (an S) and qam (three dots) drawn on the trackpad's round shape). A full rebuild and --add-sets with steam do that step themselves; --add-sc2 does it alone, in place, without the Kenney pack: python -I scripts/build_prompt_pack.py --add-sc2 --out assets/prompts/prompt_icons.pak
The Steam Deck prompt style uses the deck/ icons (Kenney's Steam Deck art); its Steam and quick-access buttons use steam/guide and steam/qam.
